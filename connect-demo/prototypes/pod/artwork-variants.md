## Template-dependent conversion checklist
1. In the authorized supplier product editor, select the exact variant and obtain the official print template.
2. Record print area, units, resolution, bleed, safe zone, permitted formats, maximum file size and color instructions.
3. For cotton tote: fit contained motif to verified print placement and export accepted transparent raster if required.
4. For AOP tote: extend pattern across the official bleed, align all required separate panels, and preserve important details inside the safe area.
5. Validate dimensions, transparency and embedded colors against supplier instructions; generate mockup in supplier editor.
6. Obtain quote, request owner approval for sample order, inspect sample, and only then finalize listing.
