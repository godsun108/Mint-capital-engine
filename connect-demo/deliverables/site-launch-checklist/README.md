# Small Website Launch Checklist

A ruthless final pass for a small website. The goal is not ceremony; it is making sure a stranger can understand, trust and use the site.

## 1. Five-second test
Without scrolling, can a stranger tell:
- [ ] what this is;
- [ ] who it is for;
- [ ] what they should do next?

Rewrite the headline until the answer is yes.

## 2. Primary journey
Complete the site's main action on a phone and desktop.
- [ ] Primary CTA works.
- [ ] Forms submit and give clear feedback.
- [ ] Checkout/contact/download path reaches the expected destination.
- [ ] Important links are not broken.
- [ ] Back/navigation behavior is understandable.

## 3. Mobile
- [ ] No horizontal overflow.
- [ ] Text is readable without zooming.
- [ ] Buttons/links are easy to tap.
- [ ] Navigation works at narrow width.
- [ ] Images/media do not dominate the page unnecessarily.

## 4. Discovery
- [ ] Unique useful page title.
- [ ] Accurate meta description.
- [ ] Canonical/public URL is correct.
- [ ] Intended public pages are crawlable.
- [ ] Sitemap exists when useful.
- [ ] Social preview metadata/image is sensible where applicable.

## 5. Trust
- [ ] Prices and commercial claims are accurate.
- [ ] Contact/support path is real.
- [ ] No fake testimonials, customer counts, scarcity or badges.
- [ ] HTTPS works.
- [ ] Refund/return expectations are visible where applicable.
- [ ] Privacy/terms disclosures appropriate to the site are addressed.

## 6. Performance sanity pass
- [ ] Hero media is reasonably sized.
- [ ] No obvious console-breaking errors.
- [ ] Page loads acceptably on a normal mobile connection.
- [ ] Third-party scripts are limited to things that provide real value.

## 7. Launch record

```
Site:
Launch date:
Primary customer:
Primary action:
Production URL:
Contact/support path:
Payment path tested:
Mobile tested:
Discovery metadata checked:
Known limitations:
Next review:
```

## 8. Stranger test
Give the page to someone without explaining it and ask:
1. What do you think this does?
2. What would you click?
3. What makes you hesitate?

Do not coach them. Their confusion is data.

## Final 10-minute pass
Headline → mobile → CTA → contact → price → payment/download → metadata → important links → HTTPS → one stranger's eyes.

This is general launch guidance, not legal, accessibility, security, privacy, SEO, or compliance certification.
