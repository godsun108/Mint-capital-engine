# MINT // FIRST OFFER GATE

MINT is blocked on one truthful, deliverable offer.

The machine may prepare an offer, but a human must approve:
- what is actually delivered;
- price and any costs;
- delivery timing;
- refund/cancellation obligations;
- where/how it may be published;
- any regulated/licensed boundary.

No customer, demand, sale, payment, eligibility, or settlement may be invented.

## Candidate lanes

MINT can accept any real lane that fits the contract:
- SERVICE — bounded work deliverable for a buyer.
- PRODUCT — a real physical/digital product that can be fulfilled.
- COMMISSION — only where the user is actually authorized/licensed and the external program permits it.
- RECEIVABLE — only a genuine amount already owed.
- CLAIM — only after authoritative-source eligibility review.

The first approved lane should be chosen for shortest credible path to settled cash, not largest imagined upside.
