# Foundry Express TypeScript Starter

A small reusable Express + TypeScript starter intended to reduce initial project setup work.

Included: strict TypeScript configuration, Express server, JSON middleware, health route, development/build/start scripts, and an environment example.

Quick start: `npm install` then `npm run dev`. Production build: `npm run build && npm start`.

No claim is made that this is the best starter or that it guarantees time savings. Review dependencies and configuration for your own production requirements.
