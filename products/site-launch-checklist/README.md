# Small Website Launch Checklist

A practical final pass before publishing a small business or project website.

## Message
- [ ] The first screen says what the business/project does.
- [ ] Primary action is obvious.
- [ ] Contact path works.
- [ ] Prices or next-step expectations are clear where appropriate.

## Mobile + usability
- [ ] Important pages are usable on a phone.
- [ ] Navigation works without precision tapping.
- [ ] Forms have useful labels and error states.
- [ ] Images do not obscure important text.

## Discovery
- [ ] Every important page has a descriptive title.
- [ ] Meta description is present where useful.
- [ ] Pages intended for discovery are crawlable.
- [ ] Sitemap/robots configuration is intentional.
- [ ] Social-share preview has been considered.

## Trust + operations
- [ ] Claims can be substantiated.
- [ ] No placeholder contact information remains.
- [ ] HTTPS is working.
- [ ] Analytics/telemetry choices match the privacy approach.
- [ ] Terms/privacy/refund information is included when applicable.

## Final test
- [ ] Test the primary customer journey from a fresh browser.
- [ ] Test every payment/contact/download action.
- [ ] Confirm success and failure states.

This is a general launch aid, not legal, accessibility, security, or compliance certification.
