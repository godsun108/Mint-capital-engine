# MINT // AUTONOMOUS REVENUE PORTFOLIO

Objective: maximize lawful settled net cash by operating multiple bounded revenue systems in parallel.

## Agent classes
CREATE: digital products, software, productized services, subscriptions, licensing, rights-cleared assets.
EARN: verified commission/referral routes where authorization and program terms permit.
CLAIM: grants, rebates, refunds, unclaimed property, reimbursements and genuine receivables.
SAVE: recurring-cost review, renewals, comparisons and negotiation preparation.
ACCESS: research asset conversion and financing; borrowing, collateral and account actions remain human-gated.
INVEST: autonomous research/simulation only; live securities, derivatives and crypto execution remain human-gated.

## Shared loop
DISCOVER -> VERIFY -> SCORE -> PREPARE -> MANDATE -> EXECUTE -> FULFILL -> RECONCILE -> LEARN -> REPEAT

Agents prioritize expected net cash, time-to-cash, human time, upfront cost, repeatability and evidence quality. A priority score is not a profit guarantee.

## Truth
Discovered is not verified. A lead is not a customer. Paid is not settled. Expected money is not cash.
Never fabricate customers, demand, reviews, invoices, eligibility, identity, credentials, payments, awards, balances or settlement.
