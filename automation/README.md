# MINT AUTONOMY

MINT may continuously discover, prepare, publish, fulfill and reconcile an approved offer only inside a human-defined standing mandate.

A mandate defines the offer, channels, price bounds, fulfillment permission and cost ceilings. Anything outside those limits stops for review.

The local control plane never claims an external action occurred. Provider adapters must independently verify the mandate before each external write.

Hard stops: borrowing, trading, opening financial accounts, user-account transfers, regulatory attestations, changing mandate limits, or regulated representations outside verified authorization.

Autonomy does not imply guaranteed revenue.
