# Initial Workforce

Discovery: SCOUT, Grant Scout, RFP Scout, Property Scout, Arbitrage Scout.

Intelligence: Oracle, Research Desk, Competitive Intel, Data Refinery.

Production: Builder, Website Rescue, Document Factory, Content Engine.

Commerce: Merchant, MARKET, CONCIERGE, Closer, Prospector.

Media: Newsletter, Directory.

Products: Micro-SaaS, API Product, Creator Back Office, Property Intelligence.

Finance: MINT, Revenue Analyst, Cost Controller.

Control: Auditor, Compliance, Security, Governor, FORGE.

## Expansion rule
Add a new named agent only when it has a distinct objective, tool/permission boundary, or measurable KPI. Otherwise add a capability to an existing primitive. This prevents a theatrical swarm of duplicate prompts while allowing the workforce to grow when specialization has economic value.
