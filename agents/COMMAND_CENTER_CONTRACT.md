# Portal AI Company Command Center Contract

Portal may present Agent Company state but does not become the economic ledger or executor.

## Read model
Portal can display:
- workforce by division and status;
- mission/job dependency graph;
- evidence and provenance links;
- pending human approvals;
- experiment hypothesis and thresholds;
- settled revenue, costs and contribution from MINT;
- FORGE comparisons;
- kill-switch state and audit events.

## Human controls
Portal may request:
- approve / reject a specific consequential action;
- pause/resume a task;
- halt/resume an agent or division;
- system emergency halt;
- start a sandbox mission;
- graduate an evidence-qualified workflow to the next stage.

Every control emits an auditable command. UI state alone never constitutes approval.

## Visual doctrine
The command center should feel like a living organization, not an admin spreadsheet: divisions as stations, agents as workers, jobs as moving work orders, approvals as gates, and economics as an instrument panel. Truth labels remain literal: SIMULATION, SANDBOX, PILOT, PRODUCTION.
