# MINT Agent Company

A modular workforce for lawful economic experiments.

## Loop
DISCOVER -> VERIFY -> SCORE -> BUILD -> PACKAGE -> OPERATE -> MEASURE -> LEARN

Agents do not receive unrestricted autonomy. Every task carries a capability set, budget ceiling, evidence requirements and an approval policy. Consequential actions remain human-gated under ../AUTOMATION_CONTRACT.md.

## Primitives
- discovery: find public opportunities and evidence
- research: verify demand, economics and constraints
- production: create bounded digital assets/services
- commerce: package approved offers and serve inbound demand
- measurement: attribute revenue/cost and evaluate experiments
- governance: enforce approvals, budgets, audit logs and stop conditions

See registry.json for the initial workforce and runtime.js for the dependency/authorization-aware task planner.
